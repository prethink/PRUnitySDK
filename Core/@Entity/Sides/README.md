# Свой-чужой (Sides)

Кто кого бьёт. Каждая сущность стоит на какой-то **стороне**, а матрица сторон в настройках
решает, что происходит с ударом одной стороны по другой. Игроков в командах решает команда.

Удар бывает только по сущности с `HealthComponent`: ответ сторон применяется в хуке урона,
поэтому касается любых ударов — касания, ближнего боя, снаряда, взрыва — без правок в оружии.

## Стороны

`EntitySideEnumerations`: `Neutral`, `Players`, `Bots`, `Npc`, `Monsters`, `Breakables`.
Проект дописывает свои partial-классом, как любой набор перечислений.

Сторона сущности, по убыванию силы:

1. компонент `EntitySideOverride` на объекте сущности — для отдельных экземпляров;
2. у игрока — сторона его типа: `Human` → `Players`, `AI` → `Bots`, `NPC` → `Npc`;
3. у остальных — сторона вида сущности из списка в настройках;
4. иначе `Default Side` (`Neutral`).

## Матрица

`PRSDKSettings → Sides → Matrix`. Треугольник «сторона × сторона», как Layer Collision Matrix
в Unity: клетка симметрична. Нажатие переключает значение:

| Клетка | Что с ударом |
| --- | --- |
| **Бьёт** | обычный удар (по умолчанию) |
| **Без урона** | попадание засчитано, эффекты и звук играют, цель цела |
| **Не бьёт** | удар отклонён (`Blocked`), эффекты урона молчат |

Пустая матрица — «все бьют всех», поэтому включённые стороны ничего не меняют, пока
матрицу не настроили.

## Команды

Если оба — игроки в командах (`PlayerTeam` не `Default`), решает команда, а не матрица:
одна команда — не бьют друг друга (`Friendly Fire` — бьют), разные — бьют. Команда `Default`
означает «без команды», и такие игроки решаются матрицей по сторонам.

## Из кода

```csharp
Enumeration side = EntitySides.GetSide(entity);
EntitySideDamage damage = EntitySides.GetDamage(attacker, victim);   // Hit / NoDamage / Block
bool canHit = EntitySides.CanHit(attacker, victim);   // удар засчитается (в том числе без урона)
bool enemy = EntitySides.IsEnemy(bot, target);        // удар наносит урон — по этому выбирают цели
bool ally = EntitySides.IsSameTeam(a, b);
```

## Устройство

| Файл | Роль |
| --- | --- |
| `EntitySides` | ответ «чья сторона» и «что с ударом» |
| `EntitySidesSettings`, `PRSDKSettings.Sides` | настройки: стороны игроков и видов, матрица, friendly fire |
| `EntitySideMatrix` | матрица; хранит только клетки, отличные от «бьёт» |
| `EntitySideDamageRule`, `PRUnitySDK.Sides` | правило урона; SDK ставит его сам на старте, если `Enabled` |
| `EntitySideOverride` | своя сторона отдельной сущности |
| `Editor/EntitySideMatrixDrawer` | матрица треугольником в инспекторе |

Правило сторон стоит в общей очереди правил урона (`DamageRules`) на `Order = -200`.
Правила проекта и сцены (`DamageRuleComponent`) продолжают работать рядом с ним.
