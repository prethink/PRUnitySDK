# UIButtonDefinition

Переиспользуемое описание экранной кнопки: IIconProvider, ILocalizationProvider,
ActionBase, необязательное окно MonoWindowsTracker, горячая клавиша, условие
уведомления и эффекты. Здесь только данные и выполнение действия; визуальная
панель проекта находится в PRUnitySDKPrivate/Components/Buttons.

Создание: Create → PRUnitySDK → UI → Button. Icon задаёт спрайт иконки,
Background — подложку, Decoration — необязательную картинку между ними, например лучи.
Icon Size и Decoration Size независимо задают размер каждого слоя относительно подложки:
1 означает 100%, 0.6 — 60%; значения больше 1 выходят за края подложки.
Пропорции спрайтов сохраняются, слои остаются по центру. По умолчанию размеры равны
0.74 и 1, поэтому существующие кнопки сохраняют вид. Чтобы лучи выглядывали из-за иконки,
например, задайте Icon Size = 0.6 и Decoration Size = 1.2.
Description хранит ключ и три перевода.
Label дополняет отсутствующие значения из UIButtonLabels, сохраняя ключ для базы.

Effects.IconRotationSpeed и Effects.DecorationRotationSpeed задают независимое
вращение иконки и промежуточной картинки в градусах в секунду игрового времени.
Ноль выключает вращение; знак меняет направление. Без Decoration слой не создаётся.
Effects.RotateIconOnlyWhenAttention оставляет вращение иконки только на время, пока выполнено
условие внимания; когда оно снимается, иконка встаёт ровно. Так кнопка колеса крутится, пока
его можно крутить, — вместо пульса (Effects.PulseWhenAttention выключают отдельно).
Вид обновляет анимации через PRMonoBehaviour и PRTime.Instance.GameDeltaTime: логическая пауза
останавливает вращение и пульсацию, после неё они продолжаются с сохранённой фазы.

Effects.ScaleOnHover увеличивает подложку в Effects.HoverScale раз, пока над кнопкой курсор
(по умолчанию включено, 1.08); переход длится Effects.HoverDuration секунд реального времени.
Масштаб наведения перемножается с пульсом внимания. Область нажатия не растёт — увеличивается
только подложка, поэтому на краю кнопки эффект не мерцает. Неактивная кнопка не увеличивается.
На телефоне касание даёт тот же эффект, пока палец на кнопке.

Timer — необязательный источник обратного отсчёта (IButtonTimer), выбирается как условие
внимания. Пока источник говорит, что ждать есть чего, внизу плашки идёт «мм:сс» (от часа —
«чч:мм:сс»). Опрашивает его UIButtonTimerWatcher (WatcherTask) раз в секунду реального времени;
надпись меняется только при смене значения. Наблюдатель стартует вместе с наблюдателем внимания —
после готовности данных. Источники лежат рядом со своими системами: WheelOfFortuneButtonTimer,
FreeGiftButtonTimer, DailyGiftButtonTimer.

Metric Key задаёт ключ метрики нажатия: PRUnitySDK.Metric.Send("button", "click", MetricKey).
Пустая строка или только пробелы отключают отправку. Метрика отправляется после успешной
проверки CanInvoke, до выполнения действия: отказ Action.Execute или открытия окна
не отменяет учёт нажатия. Клик, касание и горячая клавиша используют один Invoke.

Invoke нажимает кнопку: выполняет её через Execute и сообщает о нажатии в шину. Execute проверяет
CanInvoke, отправляет метрику, вызывает Action.Execute и затем открывает Window, если включён
Open Window. При отказе действия окно не открывается. Наследник переопределяет CanInvoke и Execute;
сам Invoke не виртуальный, чтобы событие нажатия не терялось. Состояние доступности проверяется
при каждом нажатии.

Ignore Pause разрешает кнопке работать на логической паузе: панель кнопок на паузе нажатий не принимает, и кнопка,
которую выделило обучение или которая должна открывать окно во время катсцены, иначе оставалась бы мёртвой.
Открытое окно блокирует и такую кнопку. По умолчанию галка снята.
Эффекты такой кнопки — пульс, вращение иконки и лучей — на паузе тоже идут: кадры ей раздаёт панель,
по реальному времени, потому что игровое на паузе стоит.

## Событие нажатия

Каждое нажатие — мышью, касанием или горячей клавишей — рассылает в шину `IUIButtonPressedEvent`:

```csharp
public class OpenShopStep : PRMonoBehaviour, IUIButtonPressedEvent
{
    [SerializeField] private UIButtonDefinition shopButton;

    public void OnUIButtonPressed(UIButtonDefinition button, bool executed)
    {
        if (button == shopButton && executed)
            Complete();
    }
}
```

Какая кнопка нажата, слушатель узнаёт сравнением с нужным ассетом: описание одно на все панели,
где кнопка стоит. `executed` — сработала ли она: `false` означает, что нажатие было, но действие
отказало или окно не открылось. Событие нужно тем, кто следит за игроком со стороны, — шагу
обучения, подсказке, счётчику; сама кнопка о них не знает. Пока общий экранный интерфейс
не принимает нажатия (пауза, открытое окно, ввод текста), события нет.

UIButtonAttentionWatcher принимает уникальный ключ, ICondition и интервал. Владелец
должен дождаться готовности данных источника, подписаться на Changed, зарегистрировать
задачу в PRUnitySDK.Trackers.BackgroundTasks и вызвать Execute для первого чтения.
При выключении UI отписать Changed и вызвать Unregister. Условие должно быть дешёвым
и не менять данные. Пустое условие этого наблюдателя означает отсутствие уведомления.

Не храните наблюдатели, угол вращения или флаг уведомления в ScriptableObject:
одним определением могут одновременно пользоваться несколько панелей.

## Редактор кнопок

Откройте PRUnitySDK → Windows → Buttons. Окно автоматически находит все
UIButtonDefinition проекта, включая наследников: слева карточки с подложкой,
Decoration и иконкой, справа существующий инспектор выбранной кнопки.
Превью учитывает размеры слоёв и целиком помещает композицию в карточке.
Поиск учитывает имя и путь ассета, ключ локализации и переводы; фильтр выбирает тип.

«Создать» предлагает путь нового ассета и открывает его для настройки.
«Сохранить» записывает изменения выбранной кнопки, «Показать» подсвечивает её
в Project. Список обновляется при изменении ассетов и Undo/Redo; поиск, выбор
и прокрутка сохраняются при перекомпиляции.
