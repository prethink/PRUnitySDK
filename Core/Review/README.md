# Review

Оценка игры на площадке: `PRUnitySDK.Review` (`IReviewService`).

Окно оценки принадлежит площадке, игра его только открывает и узнаёт итог.

```csharp
IReviewService review = PRUnitySDK.Review;

if (review.CanRequest)
{
    review.Completed += sent => { /* true — оценка поставлена */ };
    review.TryRequest();
}
```

| Член | Смысл |
| --- | --- |
| `CanRequest` | можно ли спросить сейчас |
| `TryRequest()` | открыть окно оценки; `false` — окно не открыто, `Completed` не придёт |
| `Completed` | окно закрыто: `true` — оценка поставлена, `false` — закрыто без неё |
| `AvailabilityChanged` | `CanRequest` мог измениться |

## Реализации

| Служба | Когда |
| --- | --- |
| `UnavailableReviewService` | по умолчанию: спросить некого, `CanRequest` всегда ложно |
| `YandexReviewService` | интеграция с Яндексом (`YG2.Integration/Review`) |

Площадка подключает свою через `[OverrideProperty(typeof(IReviewService), …)]`.

## Чего ждать

- Спросить можно один раз за сессию. После `TryRequest()` `CanRequest` ложно до перезапуска,
  чем бы окно ни закончилось.
- `CanRequest` ложно, если игрок не вошёл в аккаунт или уже оценил игру, — причину служба не сообщает.
- Итог приходит не всегда: площадка может отказать уже после запроса, и тогда `Completed` не поднимется.
  Тот, кто ждёт итога, не должен держать на этом ожидании игру.
- Награду за оценку требования площадки не запрещают, но она должна быть одинаковой при любой оценке:
  какую оценку поставил игрок, игра не узнаёт.
