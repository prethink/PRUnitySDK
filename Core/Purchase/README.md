# Purchase

`PurchaseManager` является самостоятельным модулем покупок и не принадлежит Advertising.

Его зона ответственности:

- получение каталога и актуальных цен платформы;
- запуск и восстановление покупок;
- обработка успешного результата;
- выдача купленного содержимого;
- окно магазина и элементы товаров.

Публичный контракт `IPurchaseService` позволяет другим модулям запрашивать покупку, не связываясь с конкретной платформой. Advertising использует его только для опциональной покупки Remove Ads.

Старая реализация пока хранится в `Assets/PRUnitySDKOLD/PurchaseWindow~` как референс и будет перенесена отдельно.
