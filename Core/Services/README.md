# Сервисы PRUnitySDK

Сервисы содержат общую runtime-логику, которой могут пользоваться разные игровые
системы. Этот раздел описывает их публичный контракт, состояние и ожидаемый жизненный
цикл. Сами реализации пока могут находиться в других каталогах ядра: раздел является
единой точкой документации, а не отдельной сборкой.

## Список сервисов

| Сервис | Назначение | Доступ |
| --- | --- | --- |
| `NameService` | Выдаёт случайные уникальные имена и резервирует их | `PRUnitySDK.Utils.NameService` или `NameService.Instance` |
| `PlayerNameServiceBase` | Возвращает имя текущего локального или платформенного игрока | `PRUnitySDK.CurrentPlayerName` |

## NameService

`NameService` предназначен для ботов, NPC и других объектов, которым нужно получить
случайное имя без повторов среди одновременно существующих владельцев.

Имена загружаются при первом обращении из файла:

```text
Assets/PRUnitySDK/Resources/PRUnitySDK/Names.txt
```

Каждое имя должно находиться на отдельной строке. Пустые строки игнорируются, пробелы
по краям удаляются, а дубликаты без учёта регистра исключаются.

### Получение и освобождение имени

```csharp
private string reservedName;

private void Awake()
{
    reservedName = PRUnitySDK.Utils.NameService.GetRandomName();
}

private void OnDestroy()
{
    PRUnitySDK.Utils.NameService.ReleaseName(reservedName);
}
```

Каждый успешный вызов `GetRandomName()` сразу резервирует результат. Пока имя не
освобождено через `ReleaseName()`, сервис не выдаст его повторно. Резервирование
действует только в текущем запуске приложения и сбрасывается вместе с singleton.

`PlayerBot` уже освобождает своё имя при уничтожении. Другие потребители должны
делать это самостоятельно, когда имя им больше не принадлежит.

### Если имена закончились

Когда все исходные имена заняты, сервис сохраняет уникальность и создаёт имя с
числовым суффиксом, например `Alex 1`. Если файл не найден или не содержит имён,
используется основа `NoName`.

### Получение полного списка

```csharp
List<string> names = PRUnitySDK.Utils.NameService.GetAllNames();
```

`GetAllNames()` возвращает копию загруженного списка. Изменение этой коллекции не
меняет данные внутри сервиса и не влияет на резервирование.

> [!IMPORTANT]
> `NameService` не является источником имени пользователя. Для имени текущего игрока
> используйте `PRUnitySDK.CurrentPlayerName.Name` или
> `PRUnitySDK.CurrentPlayerName.GetCurrentName()`.

## PlayerNameServiceBase

`PlayerNameServiceBase` абстрагирует источник имени текущего игрока. По умолчанию
SDK использует `LocalPlayerNameService`; интеграция с платформой может заменить его,
например на `YandexPlayerNameService`.

```csharp
string playerName = PRUnitySDK.CurrentPlayerName.Name;
```

Этот сервис не резервирует имена и не гарантирует их уникальность.
