# ReservedItemsManager

Отвечает на один вопрос: **достаётся ли предмет игроку не покупкой**. Магазину этого
хватает, чтобы не раздавать даром то, что игрок и так получит подарком, за достижение
или из контейнера, — и при этом ничего не знать о тех системах.

## Как это устроено

Связи между системами нет. Каждая сама сообщает, что раздаёт:

```csharp
public sealed class SomeSystemReservedItems : IReservedItemsProvider
{
    public string ReservationSource => ReservedItemSources.Achievement;

    public IEnumerable<string> GetReservedItemIds() =>
        RewardItemCollector.GetItemIds(rewards);
}
```

Провайдер регистрируется в своём модуле, обычным хуком контейнера менеджеров:

```csharp
[MethodHook(MethodHookStage.PostOperation, 43)]
private void RegisterReservedItems()
{
    ReservedItems?.Register(new SomeSystemReservedItems());
}
```

Менеджер не перечисляет системы и не заглядывает в их каталоги — он видит только
интерфейс. Модуль, которого в SDK ещё нет, назовёт себя сам, и реестр примет его
без правок.

## Известные источники

`ReservedItemSources` перечисляет имена, которые SDK умеет показать игроку: награда
за достижение, ежедневный и бесплатный подарки, содержимое контейнера, вещь на уровне.
Список открыт — своё имя источник может назвать любое, оно просто покажется как есть.

Награда бывает контейнером с другими наградами, поэтому состав разбирает общий
`RewardItemCollector`: он спускается по вложенным контейнерам и возвращает идентификаторы
предметов. Разовые случаи — вещь, лежащая на уровне, — резервируются вручную через
`Reserve(itemId, source)`, а не списком из каталога.

## Как спрашивают

```csharp
if (PRUnitySDK.Managers.ReservedItems.IsReserved(item))
    // вещь добывают, а не покупают

if (PRUnitySDK.Managers.ReservedItems.TryGetSource(item.Id, out string source))
    // source — из ReservedItemSources, спрашивающий переводит его для игрока
```

Состав собирается один раз и кешируется: спрашивают об этом часто — например, на каждой
перерисовке карточки в списке. `Invalidate()` сбрасывает кеш и нужен, когда каталоги
меняются на ходу.

Что делать с ответом, решает спрашивающий. Обычное правило: бесплатную вещь, которую
выдаёт другая система, продавать не за что и раздавать нельзя — вместо цены игроку
показывают, где её искать. Платных вещей резерв не касается: если вещь и продаётся,
и выпадает из контейнера, это осознанный выбор настройки.
