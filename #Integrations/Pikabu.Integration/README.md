# Интеграция с Пикабу Играми

Связывает PRUnitySDK с [SDK Пикабу Игр](https://games.pikabu.ru/sdk/docs/intro/what-do) напрямую, без GamePush
и сторонних плагинов: запуск, облачное сохранение, имя игрока, язык, устройство, пауза на скрытой вкладке.
Реклама и покупки лежат в `PRUnitySDKPrivate/Pikabu.Integration` и относятся к этому же модулю.

Площадка в слоте «Площадка», рядом с `YG2.Integration` и `GamePush.Integration`. Включается одна из них.

## Важно

- **Включение.** *PRUnitySDK → Модули*, вкладка «Интеграции», раздел «WebGL — браузерные площадки», слот «Площадка»:
  выбрать «Пикабу Игры» и нажать «Применить». Активная платформа сборки — WebGL.
- **Хостинг свой.** Билд на серверы Пикабу не загружается: игру нужно разместить на своём сервере (HTTPS) и указать
  ссылку в Студии. Без своего сервера — только публикация через GamePush.
- **Реклама.** Полноэкранную площадка показывает не чаще раза в 120 секунд: перерыв автоматической рекламы в настройках
  не меньше 120 секунд, иначе отсчёт перед ней будет впустую. Реклама на загрузке — *Player Settings → Resolution and
  Presentation → PIKABU_PRELOADER_AD* = `true`, только на телефонах.
- **Покупки** — только у игроков с аккаунтом Пикабу; гостю площадка сама предложит войти. Сервера у игры нет, подпись
  покупки не проверяется, товар выдаётся на клиенте.
- **Редактор.** Без площадки мост её изображает: гость, хранилище в `PlayerPrefs` (`PikabuEditorStorage.*`), реклама
  «досматривается» за секунду, покупка проходит сразу, товары — из каталога проекта. Интеграцию можно гонять в редакторе.
- **Шаблон страницы** правится в `WebGLTemplate~` этой папки, а не в `Assets/WebGLTemplates/Pikabu`: копию перезапишут
  «Применить» и сборка.
- **Требования площадки:** русский интерфейс при запуске, пауза при смене вкладки, рекламе, окне входа и оплаты,
  тишина в фоне, работа с блокировщиком рекламы, облачные сохранения, никакой регистрации в сторонних сервисах.

## Из чего состоит

| Что | Где |
| --- | --- |
| Мост к `PkbSDK` | `Assets/Plugins/Pikabu/PikabuSDK.jslib` (папка плагина модуля) и `PikabuSDK.cs` |
| Шаблон страницы | `WebGLTemplate~` в этой папке; «Применить» и сборка копируют его в `Assets/WebGLTemplates/Pikabu`. Грузит `sdk.js`, запускает SDK параллельно с Unity, показывает рекламу на загрузке |

`PikabuSDK` — единственное место, которое говорит с JavaScript. Запросы асинхронные: у каждого номер, ответ
приходит через `SendMessage` на объект `PikabuSDK` и находит свой обработчик. В редакторе SDK нет, и мост его
изображает: гость, хранилище в `PlayerPrefs` (ключи `PikabuEditorStorage.*`), реклама «досматривается» за секунду,
покупка проходит сразу, а товары берутся из каталога проекта.

| Раздел | Что подменяет | SDK Пикабу |
| --- | --- | --- |
| `Bootstrap.Pikabu` | SDK собирается после `PkbSDK.init()` (не поднялся — без площадки); `gameStarted()` — когда убран экран загрузки | `init`, `gameStarted` |
| `GameDataStorage` | `IGameDataStorage`: всё сохранение строкой под ключом `prsave`. На сервер SDK отправляет сам, `Flush` — когда нужен ответ сервера | `sdk.storage` |
| `Translate` | `ILanguageManager`: русский по умолчанию (требование площадки), выбор игрока — ключ `prlang` в облаке | — |
| `PlayerNameService` | `PlayerNameServiceBase`: имя игрока с аккаунтом; у гостя — имя по умолчанию | `sdk.player` |
| `DeviceInfo` | `DeviceInfoBase`: телефон по браузеру, планшет не отличается | — |

Скрытая вкладка ставит паузу по фокусу и глушит WebAudio. Окна площадки (оплата, вход, реклама) после закрытия
возвращают фокус игре (`PikabuSDK.FocusGame`).

Нет у площадки: лидербордов, удалённых настроек, времени сервера, отзывов, метрики. Эти сервисы остаются
на реализациях по умолчанию.

## Настройка площадки

1. Студия Пикабу → «Внутриигровые товары»: товары с теми же идентификаторами, что в каталоге проекта
   (*PRUnitySDK → Game → Purchases*). Лучше делать их расходуемыми: выданное хранит сохранение игры.
2. Реклама на загрузке: *Player Settings → Resolution and Presentation → PIKABU_PRELOADER_AD* = `true`.
   Площадка показывает её только на телефонах.
3. Перерыв автоматической рекламы — не меньше 120 секунд: чаще полноэкранную площадка не показывает.
4. Игру нужно разместить на своём сервере: билд к Пикабу не загружается. Тестовая ссылка — в Студии,
   раздел «Тестирование».

## Ограничения площадки

- Облачное хранилище — 200 КБ на игрока; явных отправок — 100 за 5 минут.
- Игра, открытая на двух устройствах или вкладках, получает `REVISION_CONFLICT`: облако не принимает её сохранение
  до перезагрузки страницы. Игроку об этом говорит `PikabuStorageNotice`.
- Покупают только игроки с аккаунтом: гостю площадка сама предложит войти. Подпись покупки (JWT) нужно
  проверять на своём сервере; сервера у игры нет, и покупка выдаётся на клиенте.

## Как включить и отключить

Окно *PRUnitySDK → Модули*, вкладка «Интеграции», слот «Площадка»: выбрать «Пикабу Игры» и нажать «Применить».
Окно пишет символ `PRSDK_DISABLE_PIKABU` отключённой площадке, прячет папку `Assets/Plugins/Pikabu` в `Pikabu~`
и ставит шаблон `PROJECT:Pikabu`. Каждый новый `.cs` в папке модуля оборачивается в `#if !PRSDK_DISABLE_PIKABU`.
